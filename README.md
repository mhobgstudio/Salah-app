# SalahMaster — Interactive Prayer Learning

Master Islamic prayer (Salah) with interactive lessons, audio recitations, posture guides, and progress tracking.

## Features

- 📖 **5-Level Curriculum** — From Wudu to Tashahhud, step by step
- 🧎 **Posture Guides** — Arabic text, transliteration, translation for each position
- 🔊 **Audio Recitation** — Listen to each posture using SpeechSynthesis API
- 🧠 **Quizzes** — Test knowledge after each level
- 📊 **Progress Tracking** — Ring charts showing completion percentage
- 🔒 **Unlock System** — Complete levels to unlock the next
- 📅 **Streak Counter** — Track daily learning consistency
- 📱 **PWA Support** — Works offline after first visit

## Levels

1. **Purification** — Wudu (ablution) steps and dua
2. **The Opening** — Takbirat al-Ihram and Qiyam
3. **The Heart** — Surah Al-Fatiha verse by verse
4. **Movement** — Ruku (bowing) and Sujood (prostration)
5. **Completion** — Tashahhud, Durood, and Salam

## Quick Start

```bash
cd Salah-guide
python3 -m http.server 8080
# Open http://localhost:8080
```

## Tech

Single-file HTML/CSS/JS application. No build step, no dependencies.
